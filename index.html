☁️ Hybrid Cloud Sync

डेटा आधी या डिव्हाइसवर सेव्ह होतो. Firebase Realtime Database जोडल्यावर तुम्ही स्वतः Sync करू शकता. Cloud URL आणि वैयक्तिक सुरक्षा नियम कॉन्फिगर केल्याशिवाय क्लाउड Sync सुरू होणार नाही.

Cloud Sync कॉन्फिगर केलेले नाही. स्थानिक डेटा नेहमीप्रमाणे काम करतो.

सुरक्षा: Firebase मध्ये प्रत्येक रायडरसाठी स्वतंत्र Path आणि Authentication / Database Rules ठेवा. सार्वजनिक Read/Write नियम वापरू नका. Token या ब्राउझरमध्येच सेव्ह होतो; सामायिक फोनवर तो सेव्ह करू नका. Sync करताना Push क्लाउडमधील निवडलेल्या Path वरील डेटा बदलतो; Pull केल्यास सध्याचा स्थानिक डेटा बदलतो.
