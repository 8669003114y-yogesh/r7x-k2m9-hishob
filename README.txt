बाईक सर्व्हिसिंग: सर्व्हिस लॉग + बिल फोटो, गॅरेज तपशील + GPS नकाशा + रेटिंग, पार्ट्स लाइफ ट्रॅकर, km नुसार रिमाइंडर, मॉडेल निवड (डीफॉल्ट Suzuki Access 125) + देखभाल टिप्स + अंदाजे पार्ट्स दर + खर्च कॅल्क्युलेटर, कागदपत्र/PUC/इन्शुरन्स रिन्यूअल, चलन नोंद, ड्युटीपूर्व चेकलिस्ट, जवळचा पेट्रोल पंप/पंक्चर शॉप (Google Maps).
ॲप: नवीन डिझाईन, मोठे अक्षर मोड, आवाजाने ऑर्डर, मराठी/हिंदी/English, PIN लॉक, SOS, PDF/Excel मासिक हिशोब, ऑफलाइन, बॅकअप शेअर.

मर्यादा (प्रामाणिकपणे):
- Google Drive ऑटो-बॅकअप: Google लॉगिनशिवाय शक्य नाही. बॅकअप शेअर शीटमधून "Drive मध्ये सेव्ह" करा.
- होम स्क्रीन विजेट: वेबॲपला शक्य नाही (नेटिव्ह Android ॲप लागते). त्याऐवजी आयकॉनचे शॉर्टकट दिले आहेत.
- SOS: SMS / WhatsApp / शेअर शीटने लोकेशन लिंक जाते; सतत लाईव्ह लोकेशन WhatsApp च्या "Share live location" ने.
- पार्ट्सचे दर अंदाजे आहेत (शहर/ब्रँडनुसार बदलतात); तुमच्या गॅरेजचे दर टाकून ठेवा. सर्व मॉडेल्सची अचूक किंमत यादी देता येत नाही.
- जवळचा "स्वस्त" पंप: Google Maps उघडते; किंमत नकाशावरच बघावी लागते.
- चंद्र-तिथीचे सण (दिवाळी इ.) तुम्ही तारीख टाकून जोडा.
- हिंदी/English भाषांतर बहुतांश आहे; डेटा म्हणून तुम्ही टाकलेली नावे बदलत नाहीत.

- वन-टॅप ऑर्डर: रक्कम सेट नसेल तर रक्कम विचारणारी विंडो येते (₹0 ऑर्डर होत नाही); शेवटची रक्कम लक्षात राहते; प्रत्येक ऑर्डरनंतर Undo बटण; ✎ ने रक्कम बदला; 'Quick' नावाची चुकीची एंट्री आता चिप्समध्ये येत नाही.
- आवाजाने ऑर्डर: मराठी/हिंदी/English संख्या शब्द (साठ, पन्नास, sixty) ओळखतो; कंपनी (स्विगी, झोमॅटो…) ओळखतो; आधी तपासून मग सेव्ह (सेटिंगमध्ये ऑटो-सेव्ह पर्याय); माइक/इंटरनेट/https समस्येचे स्पष्ट संदेश; 🎤 फ्लोटिंग बटण.
- फॉर्म भरलेला असताना वन-टॅप / पोहोचलो / रिजेक्ट दाबल्यास फॉर्म पुसला जात नाही.
- नवीन रंग: केशरी बटणे + हिरवे कमाई कार्ड (सेटिंग -> रंग: केशरी / हिरवा / निळा / जांभळा).

- ऑर्डरमध्ये रेस्टॉरंट बिलाचा फोटो: फोटो ऑर्डरसोबत सेव्ह होतो आणि स्कॅन करून रेस्टॉरंटचे नाव आपोआप भरले जाते (ओळखीच्या नावांशी जुळवते, आणखी सुचवलेली नावे चिप्समध्ये). स्कॅनसाठी पहिल्यांदा इंटरनेट लागते; नाव हाताने बदलता येते.
